## Projects

### claude-tmux-control

[`claude-tmux-control`](https://github.com/gunlee01/claude-tmux-control) is a tmux-based Claude Code control CLI and interactive streaming alternative to `claude -p`.

It keeps Claude Code running in a persistent tmux session, streams one-turn JSONL events, and supports web chat integration and backend automation.
